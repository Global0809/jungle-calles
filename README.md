# Jungle Calles

[Visit the website](https://global0809.github.io/jungle-calles/)

An interactive music website for Jorge Calles, known publicly as Jungle Calles. The purple 3D stage includes illustrative animated performers, lighting controls, scroll scenes, and links to the artist's confirmed social profiles.

This repository contains the static website served by GitHub Pages from the `main` branch. The `.nojekyll` file preserves the authored HTML, JavaScript, fonts, and image assets.

The experience adapts [ThreeUI's Kage source](https://threeui.com/landing-pages/kage.html), with the artist content and stage world customized for this site. The original Kage document is retained at `landing-pages/kage.html`.

The performers are stylized illustrations; their appearances are not portraits of Jorge or verified crew members.
